# Voyc

> Voyc is a conversation intelligence and compliance monitoring platform for regulated industries (financial services, insurance). It monitors 100% of contact centre interactions with speech analytics AI, flags high-risk cases, complaints, and vulnerable customers in near real time, automates QA, and produces regulatory compliance evidence (including FCA Consumer Duty). Calls arrive from telephony platforms via SFTP or API; a Voyc API (v3) covers conversation uploads and data export, with a webhooks surface.

Generated by API Evangelist from the Voyc profile in the API Evangelist network (no provider-published llms.txt found; voyc.ai/llms.txt and api.app.voyc.ai/llms.txt both returned 404 on 2026-08-14).

## API

Voyc runs a real production API at `https://api.app.voyc.ai` but publishes **no** public
API reference, OpenAPI document, developer portal, or SDK. Integration documentation is
provided to customers during onboarding. What follows was observed unauthenticated on
Voyc's own hosts on 2026-08-14.

- Base URL: `https://api.app.voyc.ai`
- `/v3/…` — Voyc API v3, the integration surface. Credential-gated: returns HTTP 403
  `{"type":"client_error","errors":[{"code":"not_authenticated", …}]}`.
- `/api/v2/…` — the surface the Voyc web application uses (Django session cookie + `X-CSRFToken`).
- Credentials for v3 are per-organisation "app" access tokens, managed at
  `/v3/organisation/{organisationId}/app/{appId}/access-token/`.
- No OAuth 2.0, no OpenID Connect, no `/.well-known/` documents on any host.
- No rate-limit headers and no documented rate limits.
- No idempotency contract.
- Errors are `application/json` in the drf-standardized-errors envelope, not RFC 9457
  `application/problem+json`.
- [Status page](https://status.voyc.ai/): incident.io status page monitoring Voyc API
  (Conversation Uploads & Reporting), Voyc API v3 (Data Export), and Webhooks.
